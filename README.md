# Retinex-YOLO — Dataset and Data Availability Information

This repository documents the third-party datasets referenced in the manuscript **"Retinex-YOLO: Illumination-guided enhancement for low-light object detection"**, submitted to *Journal of Electronic Imaging*.

## Public dataset sources

| Dataset | Purpose | Source / access information |
|---|---|---|
| ExDark | Low-light object detection | [Exclusively Dark Image Dataset](https://github.com/cs-chan/Exclusively-Dark-Image-Dataset) |
| LOD | Low-light object detection | [Crafting Object Detection in Very Low Light](https://github.com/yanghong7410/LODDataset) |
| LOL-v1 | Paired low-light image enhancement | [RetinexNet project and dataset reference](https://github.com/weichen582/RetinexNet) |
| LOL-v2 (real and synthetic) | Paired low-light image enhancement | [Retinexformer dataset preparation instructions](https://github.com/caiyuanhao1998/Retinexformer#2-prepare-dataset) |
